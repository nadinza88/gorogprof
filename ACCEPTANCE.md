# ACCEPTANCE.md — критерии приёмки

Целевая платформа: актуальные браузеры на компьютере, планшете и телефоне.
Артефакт: адаптивное веб-приложение, опубликованное через Cloudflare Pages.
До реального выполнения проверки статус каждого пункта — «Не проверено».

## AC-001 — стартовый экран
- Дано: посетитель открывает сайт.
- Когда: страница загружается.
- Тогда: видны название, описание квеста, Фокс и робот, кнопка «Начать квест».
- Не допускается: обрезанный текст, отсутствующая кнопка, неработающие иллюстрации.
- Доказательство: скриншот.
- Результат: Не проверено.

## AC-002 — начало
- Дано: открыт стартовый экран.
- Когда: пользователь нажимает «Начать квест».
- Тогда: показан вопрос 1 из 9 и четыре варианта.
- Результат: Не проверено.

## AC-003 — прогресс
- Дано: квест запущен.
- Когда: пользователь переходит дальше.
- Тогда: индикатор показывает верный номер, например 2/9.
- Доказательство: ручная проверка первых трёх шагов.
- Результат: Не проверено.

## AC-004 — выбор
- Дано: вопрос с четырьмя вариантами.
- Когда: пользователь выбирает вариант.
- Тогда: выбранный вариант визуально выделен, нет двух выборов одновременно.
- Результат: Не проверено.

## AC-005 — назад и изменение ответа
- Дано: пользователь прошёл несколько шагов.
- Когда: возвращается назад и меняет ответ.
- Тогда: ответы других шагов сохраняются, итог пересчитывается.
- Не допускается: двойное начисление баллов.
- Результат: Не проверено.

## AC-006 — отмена выбора
- Дано: на текущем вопросе выбран вариант.
- Когда: нажата кнопка «Отменить выбор».
- Тогда: выбор только текущего вопроса сброшен.
- Результат: Не проверено.

## AC-007 — полное прохождение
- Дано: пользователь отвечает на девять вопросов.
- Когда: завершён вопрос 9.
- Тогда: открывается карта интересов.
- Не допускается: итог при неполном наборе ответов.
- Результат: Не проверено.

## AC-008 — подсчёт
- Дано: известный тестовый набор ответов и весов.
- Когда: считается результат.
- Тогда: результат одинаков для одинаковых ответов и проверяется unit-тестами.
- Результат: Не проверено.

## AC-009 — итоги и рекомендации
- Дано: квест завершён.
- Когда: отображена карта интересов.
- Тогда: есть несколько категорий, ведущие интересы и подходящие идеи.
- Не допускается: представлять результат как диагноз или достоверный прогноз профессии.
- Результат: Не проверено.

## AC-010 — адаптивность
- Дано: ширина экрана 360 px, 768 px или 1366 px.
- Когда: просмотрены старт, вопрос и итог.
- Тогда: нет горизонтальной прокрутки, текст читаем, кнопки удобны.
- Доказательство: скриншоты каждой ширины.
- Результат: Не проверено.

## AC-011 — клавиатура
- Дано: пользователь не использует мышь.
- Когда: перемещается Tab/Shift+Tab и активирует элементы Enter/Space.
- Тогда: фокус видим, порядок логичен, действия доступны.
- Результат: Не проверено.

## AC-012 — приватность
- Дано: ребёнок проходит квест.
- Когда: использует сайт.
- Тогда: не требуется аккаунт или личная информация, ответы остаются в браузере.
- Не допускается: запросы к стороннему API с ответами или трекеры без решения владельца.
- Доказательство: просмотр сети браузера и кода.
- Результат: Не проверено.

## AC-013 — ссылка на клуб
- Дано: пользователь на экране результата.
- Когда: нажимает кнопку о клубе.
- Тогда: открывается настроенный URL или видна временная заглушка до настройки.
- Результат: Не проверено.

## AC-014 — сборка и preview
- Дано: чистая копия репозитория.
- Когда: выполняются реальные команды из README.
- Тогда: тесты и сборка дают подтверждённый результат, Cloudflare Pages preview доступен.
- Не допускается: указывать успешный статус без реального запуска.
- Доказательство: вывод тестов/сборки и preview URL.
- Результат: Не проверено.
